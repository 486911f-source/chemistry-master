# Chemistry Master — 無料PWA版

## できること
- iPhone Safari／Android Chromeのホーム画面に追加して使えるWebアプリ
- 教科書写真を複数枚まとめて選択。カメラ撮影したページも追加可能
- 選択した写真を1枚ずつ順番にOCR
- 内蔵の高校化学辞書・基本的な反応式パターンから四択問題を作成
- 4つの選択肢すべてに解説を表示
- 1問ごとの制限時間（30／45／60／90／120秒／制限なし）
- 時間切れを自動記録し、「間違えた問題」と「時間切れの問題」を分けて再演習
- 問題・設定・回答履歴をブラウザ内に保存
- アプリ内の利用にAPIキーや有料AI契約は不要

## デザイン
白を基調に、ベンゼン環の内側に三角フラスコを配置したロゴ。深い青緑・ミント・スレートブルーをアクセントにしています。

## 最初に知っておいてほしいこと
この無料版は生成AIではありません。OCRで読み取った文章を、内蔵の化学式・用語辞書と基本的な反応式パターンに照合して問題を作ります。辞書にない内容、複雑な反応機構、図表、手書き文字、計算過程などは問題化できない場合があります。OCRにも誤認識があるため、読み取り内容と問題・解説は教科書で確認してください。

Tesseract.jsと日本語・英語OCR用データはjsDelivrから取得します。写真そのものはアプリから外部サーバーへ送信せず、端末内で処理します。初回のOCRにはインターネット接続が必要です。アプリ本体は初回アクセス後、Service Workerでキャッシュされます。

## ホーム画面に追加できる状態にする
チャットのZIPファイルから、iPhoneのホーム画面へ直接アプリをインストールすることはできません。PWAとして追加するには、先にアプリをHTTPSのWebサイトとして公開する必要があります。このプロジェクトは、無料のGitHub Pagesで公開できます。GitHub Freeでは、公開リポジトリからGitHub Pagesを利用できます。

### iPhoneだけで公開する手順
1. このZIPをiPhoneの「ファイル」アプリに保存して、タップして展開します。
2. SafariでGitHubにログインし、**New repository** から `chemistry-master` という名前の **Public** リポジトリを作ります。
3. 展開したフォルダを開き、`index.html`、`styles.css`、`app.js`、`manifest.webmanifest`、`sw.js`、`icon-192.png`、`icon-512.png`、`README.md` をリポジトリの最上位にアップロードします。ZIP自体はアップロードしません。
4. リポジトリの **Settings → Pages** を開きます。
5. **Build and deployment** で **Deploy from a branch**、branch `main`、folder `/(root)` を選び、Saveします。
6. Pages画面に表示された `https://ユーザー名.github.io/chemistry-master/` のURLをSafariで開きます。

公開リポジトリのファイルは誰でも閲覧できます。個人情報や教科書の写真などはリポジトリに入れないでください。このアプリの写真はアップロードされず、ブラウザ内で処理されます。

## iPhoneのホーム画面に追加
1. 公開されたHTTPSのURLを **Safari** で開きます。
2. **共有** をタップします。
3. **ホーム画面に追加** を選びます。
4. **ウェブアプリとして開く** が表示されたらオンにして、**追加** をタップします。

## Androidのホーム画面に追加
公開URLをChromeで開き、メニューから **アプリをインストール** または **ホーム画面に追加** を選びます。対応ブラウザでは画面上部にインストールボタンが表示されます。

## 対応目標
レスポンシブ表示と標準的なPWA機能を使用しています。iPhoneのSafari（iOS 16.4以降を目安）と、現行のAndroid Chromeを対象にしています。iOS 18系のiPhoneではSafariからホーム画面へ追加する方式です。実機での動作確認は、公開後に実際の端末で行ってください。

## データについて
登録問題・回答履歴・制限時間設定は、そのWebサイトのブラウザ内（localStorage）に保存されます。同じ公開URLで使い続ければ基本的に保持されますが、ブラウザのサイトデータを消去したり、公開URLのドメインを変更したりすると引き継がれません。


## 大学入試・応用モード（追加機能）

出題レベルで「大学入試・応用」を選ぶと、OCR文章に該当単元・必要な化学式が含まれる場合、内蔵の確認済みテンプレートから典型的な考察問題を追加します。現在の対応例は、中和の正味イオン反応式、発熱反応と平衡移動、緩衝液、過マンガン酸イオン中のMnの酸化数、酢酸エチルの生成、エチレンの付加重合です。

このモードは生成AIではなく、条件一致型の問題バンクです。教科書の記述を自由に解釈して未知の入試問題を無制限に作る機能ではありません。対象範囲に一致する問題がない場合は、応用問題は追加されません。
